# Vosk Offline — отчёт о миграции

Дата: 20 ноября 2026. Устройство: CPH2727, Android 16, ARM64.
Статус: **приёмка ТЗ №7 не пройдена**. Vosk интегрирован и проверен на устройстве; production оставлен с ручным управлением и диагностикой голоса без действий.

## Реализация

Активная точка входа `lib/main.dart` использует `VoskService`, MethodChannel и
EventChannel. Единственный владелец микрофона — Android AudioRecord в VoskBridge:
PCM16 little-endian, 16000 Hz, один канал. Формат проверяется после открытия.
Запись и распознавание идут на одном фоновом исполнителе, модель переиспользуется.
Ограничения сессии: до 6 секунд, начальная тишина до 3 секунд; окончания фраз —
Vosk endpoint, доступно ручное завершение и отдельная отмена.

Модель: `vosk-model-small-ru-0.22`, официальный архив:
https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
SHA256 архива: `961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4`.
Лицензия модели: Apache 2.0 согласно https://alphacephei.com/vosk/models.
Текст лицензии включён в assets. Манифест SHA256 проверяет каждый файл модели;
неполная установка не используется, распаковка производится локально.
Модель включена в APK; загрузок при старте приложения нет.

Библиотеки: `com.alphacephei:vosk-android:0.3.75@aar`,
`net.java.dev.jna:jna:5.18.1@aar`, как в официальном Android-примере:
https://github.com/alphacep/vosk-android-demo/blob/master/app/build.gradle.

Грамматика содержит 11 разрешённых фраз и `[unk]`. На устройстве через
официальную функцию `vosk_model_find_word` проверены все 14 уникальных слов:
начать, начни, запусти, закончить, останови, стоп, что, впереди, передо, мной,
опиши, окружение, обстановку, вокруг. Отсутствующих слов нет.

`VoiceCommandRouter` принимает только целую фразу из грамматики, только финальный
результат и только один раз для текущей сессии. Промежуточные результаты видны,
но не вызывают действия. Нечёткое сопоставление и удаление посторонних слов
не применяются. Обе команды описания используют существующее описание сцены:
до трёх свежих подтверждённых групп, лимит 1500 мс. При отсутствии актуальной
камеры: «Нет свежих данных с камеры». Метры не выводятся без измерений.

Остановка YOLO не уничтожает голосовой сервис. Камера может быть открыта командой
«Начать» после отсутствия активного контроллера. Постоянного прослушивания нет.
Старые Google STT и wake word не вызываются рабочей страницей.

## Safety и TTS

Реализации YOLO, SafetyService v5, SmartSceneAnalyzer и SafetyTTSService при этой
миграции не изменялись. Используется прежний один TTS и прежние приоритеты.
Его callback сначала инвалидирует сессию Vosk, освобождает микрофон, затем
разрешает озвучивание. Пока модель загружается и микрофон ещё не занят, отмена
не ждёт загрузку модели. После озвучивания устаревшие результаты не выполняются.
При сворачивании сессия отменяется в Dart и Android.

Проверки: общий набор 116 тестов прошёл до последних диагностических дополнений;
ещё два теста интеграции прошли отдельно: критическое предупреждение во время
записи и повторный Start после Stop. Итоговые analyze/test/build повторяются
после завершения изменений. Существующие тесты свежести, cooldown, группировки,
приоритетов и единственного говорящего движка остаются в общем наборе.

## Whisper

Whisper не создаётся рабочей страницей и MainActivity. CMake-сборка Whisper
отключена, `ggml-tiny.bin` исключён из pubspec assets. В проверенном release APK
нет записей Whisper/ggml и `libnavigation_whisper.so`; библиотеки Vosk/JNA есть.
Старые исходники сохранены локально и в Git:
`refs/archive/whisper-before-vosk`, commit
`6b5a5a7d9ce3d0367d2c42af776d1e8b35e7dc7d`.
Основная ветка и пользовательский индекс этим архивированием не изменялись.

## Первые измерения

Первая загрузка с проверкой/распаковкой: **8232,04 мс**. Это холодный запуск,
не задержка распознавания и не стоимость каждой команды.

Пользователь подтвердил успешную работу первого прогона четырёх команд в обычном
приложении без интернета: «Начать», «Что впереди?», «Опиши окружение», «Закончить».
Это качественный smoke test 4 команд, а не выполненная серия 40 попыток.
Из доступного вывода подтверждены сырые `начать` (session 1) и `закончить`
(session 8), с реальным `running=true` и `running=false` после действий.
Полная исходная серия не сохранилась в кольцевом logcat; её нельзя использовать
для расчёта точности и квантилей. Для дальнейших проб добавлено сохранение
текста/метрик и действий в ограниченный JSONL (до 1 MiB), без записи аудио.

Старый замер `after_speech_ms` по последнему кадру RMS >= 0.004 оказался
чувствителен к фоновому шуму. Теперь основной замер использует временную метку
последнего слова Vosk относительно начала записи, включая endpoint/flush;
энергетический замер сохраняется отдельно. Это оценка по выравниванию ASR,
а не независимая акустическая разметка. Длительность аудио, native compute,
полное время сессии и время с действием/TTS записываются отдельно.

## Нагрузка на YOLO

Первый сопоставимый прогон: четыре окна по ~20 секунд, порядок idle/active/active/idle,
камера, YOLO и Safety включены, модель Vosk резидентна во всех окнах. В активных
окнах обрабатывается настоящий поток микрофона без маршрутизации команд.

| Окно | Vosk | YOLO результатов/с | Camera-to-result p50 / p95, мс | RSS, MiB |
|---|---|---:|---:|---:|
| 1 | idle | 3,498 | 228,624 / 372,125 | 471,98 |
| 2 | active | 2,350 | 298,555 / 785,974 | 485,14 |
| 3 | active | 2,149 | 369,432 / 910,143 | 482,48 |
| 4 | idle | 3,299 | 253,753 / 389,781 | 494,49 |

Пул по числу результатов и длительности: idle **3,398/с**, active **2,249/с**,
просадка около **33,8%**. Этот вариант не принят. Исходные данные:
`docs/vosk_performance_before.json`. Далее проверяется минимальный приоритет
рабочего потока и размещение Vosk на эффективных ядрах; настройки YOLO не меняются.
Значения RSS — выборки, а не измеренный пик.

## Воспроизведение и оставшаяся приёмка

```powershell
flutter analyze
flutter test
flutter build apk --release --dart-define=OFFLINE_ONLY=true
flutter run --profile -t tool/vosk_offline_smoke.dart --dart-define=OFFLINE_ONLY=true -d d162aebf
# Для парного нагрузочного теста добавить --dart-define=VOSK_PERF_ONLY=true
```

Экран приёмки ведёт 10 попыток каждой из четырёх команд, 20 посторонних фраз и
20 проб тишины. Первые пять попыток команды начинаются с полностью закрытой
камерой, следующие пять — с работающими YOLO/Safety. Сохраняются ожидаемая фраза,
сырой текст, действия и метрики каждой попытки. Отрицательные пробы чередуют
оба режима. Тишина запускается серией после 60-й произнесённой пробы.

Исходная серия 40 команд, 20 отрицательных и 20 проб тишины завершена.
Цели >=36/40, >=8/10 на команду, 0 ложных действий, p50 <=1,5 с / p95 <=3 с
не достигнуты в совокупности. Полная пригодность для MVP не подтверждена.
После диагностики оставлен обычный production entrypoint в ручном резервном режиме.
Восстановлены исходные Wi-Fi=включён, mobile data=выключены, stay-on-USB=выключен.

## Результат ограниченной настройки нагрузки

Проведены ещё два одинаковых четырёхоконных сравнения; дальнейшая настройка
остановлена согласно ограничению ТЗ.

| Вариант | Idle YOLO/с | Active YOLO/с | Снижение |
|---|---:|---:|---:|
| Исходный worker priority=10 | 3,398 | 2,249 | 33,81% |
| priority=19, ядра 0–3 | 3,024 | 2,074 | 31,42% |
| То же, блоки AudioRecord 200 мс, без PSS на каждом final | 3,275 | 2,199 | 32,85% |

Это сравнения внутри каждого парного прогона, а не доказательство преимущества
между разными прогонами. Телефон нагрелся: в третьем прогоне наблюдались thermal
status=2 и shell_skin=41°C. Поэтому абсолютные скорости между прогонами нельзя
считать эквивалентными условиями. Внутри каждого прогона применён порядок ABBA.
Модель оставалась резидентной, YOLO/Safety/TTS не менялись. Рабочий поток Vosk
подтвердил `efficiency_cores=[0, 1, 2, 3] priority=19`.

Файлы: `vosk_performance_affinity.json`, `vosk_performance_stream.json`.
Последний вариант **не прошёл требование отсутствия существенной регрессии YOLO**
при непрерывной записи. Редкие Push-to-Talk команды и непрерывный стресс-тест —
разные нагрузки; первый положительный пользовательский отзыв не снимает эту
регрессию. Ручные Start/Stop сохранены как резерв для MVP. Заявлять полную
пригодность и неизменность задержки предупреждений по этим данным нельзя.

Кэшированная загрузка модели перед человеческой серией: 7008,11 мс (однократно
на запуск процесса). Старые 8232,04 мс и 20095,96 мс относятся к другим условиям
первой установки/проверки; они не являются стоимостью каждой команды.

Финальные автоматические проверки: **118 тестов прошли** (`vosk_tests.log`).
Дополнительные тесты включают отмену при TTS, устаревший/дублированный final,
запрет partial-действий, ожидание освобождения микрофона, отказ аудио и повторный
Start после Stop. Реальный отказ системного разрешения и реальное критическое
предупреждение на устройстве пока отдельно не подтверждены.

## Решение после 80 живых проб

Исходный прогон завершён полностью. По ожидаемым фразам на экране: 28/40
успешных команд (70%); 6/20 ложных действий на посторонних фразах и 4/20 в
пробах тишины. Все исходные попытки сохранены, не удалялись и не заменялись.
Для «Опиши окружение» все 10 результатов содержат только «опиши»; произнесение
именно полной фразы пользователем отдельно не подтверждено. Это ограничивает
интерпретацию этой части теста, но не снимает отрицательные результаты остальных
контрольных испытаний и нагрузочного теста.

Примеры ошибок v1: «Не начинай» → «начни», «Не останавливай» → «останови»,
«Как начать работу» → «начать». Router получал уже усечённый текст и не мог
восстановить пропущенные слова. Поэтому [unk] и строгий текстовый Router сами
по себе не обеспечили нулевые ложные действия.

Добавлена кандидатная грамматика **v2-context-guards**: кроме разрешённых команд,
она сохраняет слова отрицания, вопроса и контекста. Эти слова/фразы не являются
командами Router. Это изменение **не имеет отдельной полной приёмки 40+20+20**;
результаты v1 не выдаются за проверку v2. Добавление guards не доказывает общую
устойчивость к посторонней речи. Калибровка уверенности не выполнена.

По умолчанию release не выполняет голосовые действия: микрофон подписан
«Проверить голос (без действий)», распознавание остаётся доступным для проверки
сырого текста. Модель в этом резервном режиме загружается при проверке, чтобы
не конкурировать с запуском YOLO без необходимости. Ручные Start/Stop и прежние
предупреждения сохранены. Profile остаётся тестовым режимом с действиями.
`--dart-define=VOSK_ACTIONS_ENABLED=true` — явное включение действий только для
дальнейших контролируемых испытаний, не признак принятой конфигурации.

**Критерий работающего production-голосового управления не выполнен.**
Сборка APK и положительный первый отзыв не считаются завершением задачи.
Ограниченный этап диагностики остановлен; версия остаётся ручным резервом MVP.

## Release-only дефект, найденный при установке

Первый итоговый release собрался, но проверка микрофона на устройстве показала
`PlatformException(model, com.sun.jna.Native, null, null)`. Причина — R8/JNA:
profile-загрузка не доказывала работоспособность минифицированного APK.
Добавлены `android/app/proguard-rules.pro` и подключение правил в release:
сохранение классов JNA и Vosk, согласно официальному примеру
https://github.com/alphacep/vosk-android-demo/blob/master/app/proguard-rules.pro.
Повторная установка и проверка завершены: Vosk в минифицированном release
загрузил модель и грамматику v2, PCM-сессия завершилась финальным JSON без
ошибки JNA. Это smoke test загрузки, не новый тест точности. Данный дефект сборки
не объясняет ошибки живого profile-прогона; его результаты остаются неизменными.

## Завершение проверки устройства

Последний release установлен на CPH2727. Проверены загрузка Vosk/JNA и одна
реальная сессия AudioRecord без выполнения действий. Словарь новой грамматики
прошёл проверку наличия слов. Это не повторная приёмка точности v2.
Ручной Start запустил offline YOLO: на экране наблюдались FPS=4,6, total=205 мс,
YOLO=192 мс, frame=720x1280. Это единичная UI-выборка, не новый бенчмарк.
Ручной Stop вернул Status: Stopped. В конце запись и детекция выключены.

RSS в 80 пробах: выборки 479,89–515,11 MiB, медиана 500,36 MiB; не измеренный пик.
RAM снималась после действия/TTS, поэтому Start меняет состояние камеры до
снятия RAM. По 20 команд на режим до начала действия: без камеры ASR p50/p95
1078,30/1550,17 мс; с YOLO/Safety 1071,17/1681,79 мс (выравнивание Vosk).

Не завершены как приёмочные проверки: повторная серия v2, реальный отказ
системного разрешения, отдельное испытание критического предупреждения на
телефоне, все пункты аппаратной устойчивости и отсутствие регрессии YOLO.
Синтетические unit-тесты приоритетов не заменяют эти проверки. Причина остановки:
ограниченный этап диагностики завершён с отрицательной приёмкой, как допускает ТЗ.
